# Banking Customer & Transaction Analysis

## 📌 Project Overview

This project analyzes banking customer, account, transaction, and loan data to identify customer behavior, transaction patterns, account trends, loan insights, and key business KPIs.

The project follows a complete data analysis workflow:

**Excel → Python → MySQL → SQL → Power BI**

---

## 🛠️ Tools & Technologies

* **Excel** – Data preparation and analysis
* **Python** – Data loading and processing using Pandas
* **MySQL** – Database management
* **SQL** – Data querying and business analysis
* **Power BI** – Interactive dashboard and data visualization

---

## 📂 Dataset

The project contains four major datasets:

* **Customers** – Customer demographic and income information
* **Accounts** – Account types and account balances
* **Transactions** – Transaction types, status, amount and payment channels
* **Loans** – Loan types, amounts and approval status

---

## 🔄 Project Workflow

1. Collected banking datasets in Excel
2. Reviewed and prepared the raw data
3. Imported Excel data into MySQL using Python
4. Created and analyzed database tables using SQL
5. Performed customer, account, transaction and loan analysis
6. Created an interactive Power BI dashboard
7. Visualized key KPIs and business insights
